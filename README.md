## 包含功能

### v2.0

- **托盘图标**：右键控制极域屏幕广播窗口
- **自动阻止**：最小化 + 禁用极域大部分窗口，不阻止极域设置，浮动工具栏等无关窗口
- **隐蔽难发现**：伪装成svchost.exe，文件名svchast.exe
- **极致小体积**：真正做到以KB为单位的大小、网络传输没压力
- **单文件使用**：一个单文件就可以使用所有功能，不需要dll
- **无需管理员**：支持无需管理员权限使用所有功能

### 极域控制

- 当前V2.0自动阻止极域屏幕广播和黑屏安静
- 可以随时阻止和恢复极域广播窗口

## 使用教程

### 伪装系统文件

下载 `svchast.exe`，**复制到 C:\Windows\System32**。

- ✅ 需要管理员权限

### 双击运行

> 程序本身可以无需管理员权限运行，但是以管理员权限运行可以有更好的效果。⚠️ 如果没有管理员权限，以普通用户权限运行即可。
